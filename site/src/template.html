Every line your coding agent writes is traced to the instruction that produced it. The record lives in your repo as git notes, travels with your code, and is redacted before it leaves your machine. So a reviewer can tell which lines were specified and which came from make it safer.

How it works

Four steps, all of them git.

  1. You prompt. A hook in your coding agent snapshots the working tree before and after the turn.

  2. The difference becomes a receipt: the prompt, the model, and the exact line ranges it changed.

  3. You commit. A git hook attaches the receipts to that commit as a git note, on a ref of its own.

  4. pblame blame joins git blame against those notes, so attribution follows each line through every later edit.

Cost: two tree snapshots per prompt, typically under 200 ms, which pblame doctor measures on your repo. And about 300 ms on each git commit, most of it Python starting up.

Install

Two minutes, then forget about it.

Requires Python 3.10+, git 2.31+ and a supported coding agent: Claude Code today. Open a fresh agent session after init, because hooks load when a session starts. 

$ pipx install git+__REPO__
$ cd your-project
$ pblame init .
$ pblame doctor          # must say "Recording is live"

# then, after a few prompts and a commit
$ pblame blame src/app.py -L 40,60
$ pblame search "make it"

The envdiff project on this page was written by Claude Code, and pblame attributes all of envdiff.py to the prompts that wrote it.
